### Step-by-Step Learning Plan

1. **База CSS:** Освойте Flexbox, CSS Grid, специфичность селекторов и CSS Custom Properties.
2. **Особенности Angular:** Изучите механизмы `ViewEncapsulation` (Emulated, None, ShadowDom) и селекторы `:host`, `:host-context`.
3. **Design Tokens:** Научитесь выстраивать систему переменных (цвета, отступы, типографика, тени) на уровне корневого слоя.
4. **Архитектура:** Изучите методологию ITCSS для структурирования стилей на крупномасштабных проектах.
5. **Компонентные библиотеки:** Разберитесь, как устраивают темы и переменные библиотеки уровня Angular Material или PrimeNG.
